# Инструкции для Claude Code

Эта папка — часть Obsidian-хранилища. Все заметки в Markdown.

## Куда сохранять
- Общий план проекта → PLAN.md
- Прогресс и логи работы → progress.md
- Задачи → tasks.md
- Отдельные заметки и идеи → папку notes/
- НЕ создавай папки "Без названия", всё именуй осмысленно

## Как писать заметки
- Задачи оформляй чеклистами: - [ ] задача
- Выполненное отмечай: - [x] задача
- Связывай заметки Obsidian-ссылками: [[имя файла]]
- Добавляй теги: #todo #done #idea #bug
- В начале progress.md указывай дату записи

## Правила
- Сохраняй прогресс только когда я прошу
- Держи структуру папок чистой
