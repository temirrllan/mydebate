# План проекта MyDebate

#project #plan

**MyDebate** — веб-платформа, объединяющая дебатные турниры и MUN-конференции Казахстана в единую экосистему: поиск, публикация, регистрация, история участия. Цель MVP — проверить Product-Market Fit.

Связанные заметки: [[tasks]] · [[progress]]

---

## Технические решения

| Параметр | Решение |
|---|---|
| Фреймворк | Next.js 14 (App Router) + TypeScript |
| Стили | Tailwind CSS |
| ORM / БД | Prisma + **SQLite** (`dev.db`) на время разработки → PostgreSQL перед деплоем |
| Авторизация | NextAuth: **email + пароль** (Google OAuth пока заглушён) |
| Просмотр БД | `npx prisma studio` |

## Ключевые договорённости

- **Гость** — строго по ТЗ: НЕ видит каталог турниров, при попытке зайти → редирект на вход.
- **Регистрация на турнир** — простая форма без шага оплаты (Kaspi добавим позже).
- **Порядок** — сначала публичная часть + функционал пользователя, затем модерация и админ-панель.
- Прогресс сохраняется только по запросу (см. CLAUDE.md).

## Роли

Гость → Пользователь → Организатор (после 1-го одобренного турнира) → Администратор.

## Дизайн-система (из макетов)

- Основной синий `#2563EB`, тёмно-navy hero-блоки, светло-серый фон, белые карточки.
- Скруглённые углы, мягкие тени, 3D-иллюстрации, чип-бейджи (формат / тип / уровень / статус).
- Гротескный шрифт (Inter-подобный). Единые Navbar + Footer на всех страницах.
- Состояния интерфейса: Loading / Empty / Error / Success. Валидация форм в реальном времени.
- Адаптив: Desktop / Laptop / Tablet / Mobile. Лёгкие анимации, доступность (клавиатура, контраст).

## Этапы работы

### Этап 0 — Каркас проекта
Next.js + TS + Tailwind, дизайн-токены, базовые UI-компоненты (Button, Input, Card, Badge, Select), Navbar + Footer, layout. Prisma-схема и первая миграция.

### Этап 1 — Данные и модели `mydebate-database`
Модели User, Tournament, TournamentSection, Registration, Favorite, Notification, SupportTicket. Enum статусов (Draft / Pending / Published / Hidden / Deleted) и ролей. Seed демо-турниров из макетов.

### Этап 2 — Авторизация `mydebate-auth`
NextAuth (email + пароль), регистрация с валидацией (уникальность email, совпадение паролей, мин. длина), хеш паролей, сессии, восстановление пароля, ролевые гейты и middleware (гость → редирект).

### Этап 3 — Публичные страницы `mydebate-frontend`
Главная (6 блоков), О нас, Помощь (FAQ-аккордеон), Правила, Контакты, Логин, Регистрация.

### Этап 4 — Ядро пользователя `frontend + backend`
Каталог «Все турниры» (поиск без перезагрузки, фильтры формат/тип/город/дата, пагинация, состояния), карточка турнира, регистрация на турнир, избранное, профиль/кабинет (вкладки: мои турниры, заявки, избранное, история, настройки).

### Этап 5 — Создание турнира `frontend + backend`
3-шаговая форма с прогресс-баром, динамические разделы, загрузка обложки/логотипа, отправка на модерацию (статус Pending).

### Этап 6 — Модерация + админка
Dashboard, таблица турниров с действиями (одобрить/отклонить/скрыть/удалить), пользователи, организаторы, обращения. Автосмена роли на Организатор после первого одобрения.

### Этап 7 — Полировка `mydebate-qa` + `mydebate-reviewer`
Состояния интерфейса, анимации, адаптив, доступность, сквозная проверка user-flow, ревью кода.
